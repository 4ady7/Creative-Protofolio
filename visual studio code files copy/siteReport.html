Welcome to Shady's Site Report Page

Here I will mainly point out what I have learned while learning.

I learned that the title tag is used to identify the page that is currently being used, allowing for more clarity when the page is actually in use. I also learned that it should be placed in the head tag.

As I continued to learn, I concluded that the anchor tag is used to link and connect the website page to a clickable identifiable word; so thats when it is clicked, it takes me where I was aiming to go.

Then, I came to know that the target=” _blank” attribute allows the opening of the page link in a new tab. The target=” _blank” attribute is placed inside the anchor tag.

Now about Validation, which helped me uncover a serious mistake. The mistake that I discovered was that my head tag was previously typed mistakenly as a header, which is incorrect. Thus, I fixed it by changing the header back to head for the head tag.

Then, I observed that the Structure of the HTML file is divided into a head tag and a body tag. The head tag includes, for example, CSS links, and the title tag. On the other hand, the body tag includes several tags like header, nav, main, aside, and footer, which could be used in a CSS file to create a layout, preferably, a grid layout.

In addition, I learned that I needed to create three CSS files: one for the desktop view, one for the mobile view, and the last one, which will include the styles that should be applied to both the mobile view and the desktop view.

One thing I would like to reflect on is how I should link images. I learned that the images should be added to the same folder where the CSS and HTML files are for better practice to maintain accessibility, and I should copy from the relative URL to maintain availability if a transition happens from one device to another. I have done that while linking my validation screenshots and my project placeholders.

I was fascinated by animation, so I learned a lot about it. One of the things that I was confused about at first when I was learning animation was that in transform, you have translate, and then you can also use translateX. At first, I was confused about that, but I learned that it's a translation on the X-axis, and the same with translateY, it's a translation on the Y-axis.

Also, I learned that if I added part of the title between the span tag, then I would be able to style one part of the title, or like I did it in my portfolio I used it with one word, split it into two, and I styled that one part differently than the other, so that it looks cooler and better.

To discuss one of the problems that I faced, My Hover effect is working perfectly on Safari Desktop view and Mobile view, but It is only working on Chrome Desktop view, and not on Chrome mobile view. Why? I do not know. This is so weird from my point of view. I hope I figure this out. Looking back, I think I was too focused on the functions and what I am currently seeing on the screen that I did not take a third-person perspective, but thanks to my tutor who offered support and help, and pointed out and reminded me that I am actually working on mobile now and that Hover effects don’t really work on mobile, as there’s no way to "hover" using touch controls, so they are mainly for the desktop version of the website.

One of the concepts, I used is the Z index, when I was facing a problem where the orange underline animation was overlaps my navigation side bar. By using the Z index, I solved this problem, so that the z index for the navigation bar is higher than the z index for the orange underline animation.

Finally, in my site report, I conclude that I have elaborated on a couple of things that I learned throughout my time as I was working on HTML and CSS.
